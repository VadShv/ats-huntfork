# План: переключение цветовой гаммы через UI (Theme Switcher)

> **Статус:** черновик плана (код ещё не пишем).
> **Цель:** дать пользователю выбирать цветовую гамму («бренд») из UI —
> так же, как сейчас переключается тёмная/светлая тема.
> **Зависимость:** реализуем ПОСЛЕ Этапа 2 плана унификации кнопок
> (`docs/plan-ui-unification.md`), чтобы смена гаммы корректно работала везде.

## Согласованные решения

1. **Область действия:** персонально (per-user), хранение в `localStorage`
   (по образцу `useColorMode`). Без бэкенда, без org-level.
2. **Объём темы:** полный бренд (палитра `brand-*`/`accent-*` + шрифт + фавиконка),
   **НО логотип-сокол выносим из темы** → он становится логотипом по умолчанию
   для ВСЕХ тем.
3. **Архитектура:** реестр тем (расширяемо). Старт с двух: `default` («Стандартная»)
   и `astra` («Astra»).
4. **Момент реализации:** после Этапа 2 (унификация кнопок на токены `brand-*`).

## Как устроено сейчас (as-is)

| Ось | Класс на `<html>` | Управление | Хранение |
| --- | --- | --- | --- |
| Тёмная/светлая тема | `.dark` | UI (`useColorMode`) + inline-скрипт от FOUC | `localStorage: reqcore-color-mode` |
| Бренд / гамма | `.astra-brand` | env-флаг `NUXT_PUBLIC_ASTRA_BRAND` → плагин `astra-brand.client.ts` | нет (только env) |

CSS: `html.astra-brand` в `app/assets/css/main.css` переопределяет
`--color-brand-*`, `--color-accent-*`, подключает шрифт `PT Astra Fact`,
неоновый focus-ring, фон auth-страниц.

### Проблема: флаг `isAstraBrand` сейчас смешивает ТРИ независимые вещи

`useAstraBrand()` используется в 9 файлах и управляет сразу:
1. **Цветовой гаммой** (через класс `.astra-brand` + CSS). ← это и есть «тема».
2. **Логотипом**: `falcon-emblem.jpg` (сокол) vs `eagle-mascot-logo.png` (орёл).
   Места: `AppTopBar.vue:259`, `layouts/auth.vue:28`, `PublicNavBar.vue:27`.
3. **Логикой ссылок и скрытием Reqcore-элементов**:
   - логотип ведёт на `/dashboard` (astra) vs внешний `marketingUrl` (дефолт):
     `AppTopBar.vue:252-255`, `PublicNavBar.vue:20-23`;
   - скрытие ссылок на GitHub Reqcore: `v-if="!isAstraBrand"`
     (`AppTopBar.vue:383,694`, `PublicNavBar.vue:41,83`).

Для UI-переключателя гаммы эти три оси надо **разделить**.

## Целевая архитектура (to-be)

### Три независимые оси

1. **Тема (гамма)** — `default | astra | …` — переключается из UI (эта задача).
2. **Логотип** — единый сокол для всех тем (решение пользователя).
3. **«Режим дистрибуции» (Huntfork vs Reqcore-опенсорс)** — оставить на env-флаге
   (`NUXT_PUBLIC_ASTRA_BRAND` или переименованный) — это про то, прятать ли
   ссылки на публичный Reqcore/GitHub и куда ведёт логотип. Это НЕ тема.

> Ключевой рефактор: расцепить «гамму» от «логотипа» и «режима дистрибуции»,
> которые сейчас завязаны на один флаг.

### Реестр тем (пример структуры, не финальный код)

```
shared/themes.ts (или app/design/themes.ts)
  THEMES = {
    default: { label: 'Стандартная', htmlClass: '',            font: 'system' },
    astra:   { label: 'Astra',       htmlClass: 'astra-brand', font: 'PT Astra Fact' },
  }
  type ThemeKey = keyof typeof THEMES
```

### Композабл `useBrandTheme()` (по образцу `useColorMode`)

- `useState<ThemeKey>('brand-theme', …)` + `computed` текущей темы;
- `set(key)` / реактивное состояние;
- вешает/снимает `htmlClass` темы на `<html>` (убирает классы других тем);
- пишет выбор в `localStorage: reqcore-brand`;
- клиентская синхронизация из реального DOM (как в `useColorMode`).

### Анти-мигание (FOUC)

Расширить существующий inline-скрипт в `app/app.vue` (сейчас ставит `.dark`
до первой отрисовки): добавить чтение `localStorage: reqcore-brand` и установку
класса темы. Скрипт уже под nonce-CSP — просто дополняем его тело.

Приоритет разрешения темы (по образцу feature-flags):
`env-форс (NUXT_PUBLIC_ASTRA_BRAND) → выбор пользователя (localStorage) → default`.

### UI-переключатель

Селектор «Цветовая схема»: Стандартная / Astra. Место — рядом с тоглом тёмной
темы. Кандидаты: `settings/account.vue` или `settings/localization.vue`,
и/или иконка в топбаре. (Согласовать при реализации.)

## Риски и заметки

- **Зависимость от Этапа 2:** пока кнопки на сырых цветах (`emerald-*`, `primary-*`,
  хардкод-хексы), смена гаммы НЕ подхватится на этих экранах. Поэтому делаем после
  унификации на токены `brand-*`.
- **Мигание при per-user:** решается inline-скриптом из `localStorage` (как `.dark`).
  Org-level потребовал бы SSR-плагина — но мы выбрали per-user, так что не нужно.
- **Именование env-флага:** сейчас `NUXT_PUBLIC_ASTRA_BRAND` завязан на всё сразу.
  При рефакторе стоит развести на «тему по умолчанию» и «режим дистрибуции».
