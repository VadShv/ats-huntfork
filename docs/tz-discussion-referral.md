## 2. Целевое поведение

### 2.1 Из профиля кандидата
«Передать коллеге» → диалог из трёх шагов в одном окне:
1. **Кому** — коллега (поиск по участникам организации с ролями recruiter / lead_recruiter / admin / owner; не из `/api/duels`).
2. **На какую вакансию** — открытые вакансии, по умолчанию отфильтрованы по тем, где выбранный коллега — рекрутёр вакансии; переключатель «все открытые». Можно «без вакансии» (как сейчас), тогда вакансию выберет получатель.
3. **Комментарий** — необязательное поле (зачем рекомендуем, что важно знать), до 500 символов; решение 11.10: не обязателен.

### 2.2 Из обсуждения
Кнопка «Передать коллеге» в меню «+» композера (раздел «Кандидат», рядом с ИИ-действиями) и в «⋯» шапки треда. Открывает тот же диалог; кандидат и текущая вакансия подставляются, в списке вакансий текущая исключена.

### 2.3 Что появляется в обсуждении
Системная запись `kind = 'system_event'`, `payloadJson.event = 'referral'` — карточка в ленте без пузыря, в стиле событий этапа:

- **В треде-источнике** (отклик, откуда передали; если передавали из профиля без отклика — в треде отклика, который создастся при принятии):
  «**Иван Петров** передал кандидата **Марии Сидоровой** · рекомендован на вакансию **Backend-разработчик** · комментарий: “…”» · статус: ожидает / принят / отклонён.
- **В треде целевого отклика** (появляется при принятии, когда отклик создан):
  «Кандидат **рекомендован** Иваном Петровым на эту вакансию · комментарий: “…”».
- Статус обновляется в той же карточке (принят → ссылка «Открыть отклик», отклонён → серый).
- Комментарий рефери — внутренний (замок), к кандидату не уходит.

### 2.4 Как получатель узнаёт
- Уведомление `notification_type = 'referral'` (новый тип) с переходом в профиль кандидата, где сверху баннер «Вам передали кандидата: принять на вакансию … / отклонить».
- Принять/отклонить — там же, без похода в Лигу. Виджет в Лиге остаётся как сводка.

### 2.5 Ограничения и права
- Передать может тот, у кого есть `application: ['read']` на кандидата/отклик; принять — только адресат.
- Нельзя передать самому себе; повторная передача тому же коллеге, пока предыдущая «ожидает», запрещена (как сейчас) — в диалоге показываем «уже передан, ожидает ответа с 10.10».
- HM и внешние рекрутёры кнопку не видят.
