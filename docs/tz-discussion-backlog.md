Дата: 08.10.2026 · Статус: план к согласованию · Источники: разбор модуля `docs/discussion-module-redesign.md` (PR #19), идеи и визуальная концепция `docs/discussion-vision.md` (PR #21), ТЗ оболочки `docs/tz-discussion-shell.md` §8, ТЗ окна `docs/tz-discussion-window.md`. Сверено с кодом `main` (`41f6aca`).

## 0. Что уже сделано (чтобы не путать с планом)

В `main`: новая оболочка (шапка-паспорт, рельса времени, цвета авторов, разделитель «Новые сообщения», пустое состояние), перевод этапа из композера с обновлением карточки, автоимпорт комментариев hh.ru при любом способе добавления резюме, личные закрепления, пагинация ленты, обсуждение отдельным окном (C2). В ветке `fix/discussion-reactions-stickers`: исправление реакций и возврат стикеров.

Не реализовано ниже сгруппировано в пять пакетов. Внутри пакета — порядок выполнения. Для каждого пункта: что видит пользователь, на чём строится в коде, критерий приёмки. Усилие: S — до 2 дней, M — до недели, L — больше недели.

## Порядок и зависимости

```
Пакет 1 ──► Пакет 2 ──► Пакет 3 ──► Пакет 4
                         │
                         └──► Пакет 5 (по мере приёмки, параллельно)
```

- Пакет 2 даёт заметный результат на существующих данных — делаем до realtime.
- Пакет 3 обязателен перед пакетом 4: ИИ-карточки и дайджест множат события, полный рефетч их не выдержит.
- Пакет 5 — отдельные задачи по 0,5–1 дню, берутся между большими пакетами.

Для каждого пакета порядок прежний: ТЗ → HTML-прототип (где меняется вид) → код в отдельной ветке → PR → приёмка на стенде. Push — только после явного подтверждения.

## Оценка целиком

Пакет 1 — 2–3 дня · Пакет 2 — 1 неделя · Пакет 3 — 1–2 недели · Пакет 4 — 1–2 недели · Пакет 5 — ~1 неделя суммарно. Итого 5–7 недель чистой работы при последовательном выполнении.
