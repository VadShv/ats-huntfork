# Huntfork Sidekick

Браузерное расширение-ассистент рекрутёра (WXT + Vue 3 + Chrome Side Panel API). Боковая панель работает поверх любого сайта и подключается к huntfork.ru (cookie better-auth, серверные ключи LLM — в расширении секретов нет).

## Возможности

- **Импорт с hh.ru (штатный флоу)** — проверка дублей по `resumeId` из URL активной вкладки, импорт резюме через официальный API с привязкой к вакансии. Эндпоинты: `/api/extension/session|check|jobs|import`.
- **Универсальный импорт кандидата** — с LinkedIn, Хабр Карьеры, GitHub и любой страницы: извлечение контента → LLM-разбор → экран «Проверка данных перед импортом» → создание кандидата с дубль-чеком (`/api/extension/capture`, `/capture-confirm`).
- **ИИ-анализ страницы** — «Сводка по странице», «Оценка соответствия вакансии», «Сводка по выделенному», перевод, карточка знаний; SSE-стриминг (`/api/extension/summarize`).
- **Живой прогресс генерации** — этапы «Читаю страницу → Думаю → Пишу» с секундомером, стрим «размышлений» reasoning-моделей, каретка, кнопка «Стоп», строка тайминга «X,X с · модель». Верификация и карточка интервью строятся посекционно из SSE partial-объектов (`/api/extension/verification/run`, `/interview-card`, `stream: true`). Подробности и контракты — [docs/sidekick-ai-streaming.md](../docs/sidekick-ai-streaming.md).
- **Вопросы по странице** — чат с контекстом страницы (`/api/extension/chat`).
- **Библиотека быстрых команд** — промпты с бэкенда (`/api/extension/prompts`).
- **«Уже в базе?»** — авто-проверка кандидата по URL профиля (`/api/extension/lookup`).
- **Заметки** — сохранение результата анализа в карточку кандидата (`/api/extension/note`).
- **PDF** — извлечение текста резюме из PDF (`/api/extension/pdf-text`).

## Структура

```
entrypoints/
  background.ts          # SW: fetch к huntfork.ru, роутер сообщений, слежение за URL вкладки
  sidepanel/             # Vue 3 панель
    App.vue              # Каркас: PanelShell + роутер views + хоткеи
    composables/         # Состояние и логика (useSidekick — протокол с background)
    layout/              # Каркасные компоненты (RailNav, TopBar, Composer…)
    views/               # Экраны (Чат, Сорсинг, Скрининг, Аутрич…)
    styles/              # Дизайн-система (--hf-* токены, светлая/тёмная тема)
  hh-list.content.ts     # Бейджи «В Huntfork» в списках резюме hh.ru
```

## Сборка

```bash
npm ci
npm run build            # → .output/chrome-mv3
```

Канонический lock-файл — `package-lock.json` (npm). Локально можно собирать и bun'ом, но `bun.lock` в репо не коммитим.

Сборка самодостаточна: `prebuild`-скрипт (`scripts/ensure-root-tsconfig.mjs`) создаёт заглушки `.nuxt/tsconfig.*.json` в корне монорепо, если их нет — без этого сборщик падал на чистом клоне (корневой tsconfig ссылается на генерируемые файлы Nuxt).

Установка: chrome://extensions → «Режим разработчика» → «Загрузить распакованное расширение» → каталог `.output/chrome-mv3`.

## Скриншот-QA

`node qa-shots.mjs` — поднимает собранное расширение в Chromium (Playwright), подставляет заглушки сообщений background и SSE-ответов, снимает все экраны в светлой и тёмной темах в `qa-shots/`.

`python3 qa-streaming.py` (Playwright for Python, через xvfb) — целевой QA живого стриминга: этапы с секундомером, partial-рендер верификации и карточки, «Стоп», контроль горизонтального перелива на узкой панели (см. шапку скрипта).

## Принципы

- Тонкий клиент: весь парсинг и LLM-вызовы на сервере, ключей в расширении нет.
- Панель живёт в chrome браузера — SPA-перерисовки hh.ru её не затирают.
- `resumeId` берётся из URL активной вкладки, а не из DOM — устойчиво к смене вёрстки.
