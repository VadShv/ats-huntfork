Однако ключ не доходил до API из-за несовпадения namespace в стеке SDK: Kilo помещал ключ в `providerOptions.openai`, а adapter `@ai-sdk/openai-compatible` читал `providerOptions.myvadshv` (по имени провайдера из конфигурации). Ключ молча отбрасывался, Cloud.ru не получал инструкции по кэшированию.

### 7. Перерасчёт стоимости

Кэш не уменьшает количество токенов — модель получает весь контекст. Кэш снижает цену чтения: кэшированные токены тарифицируются по ~0,1× от полной цены.

При работающем кэшировании (cache hit rate 70–90%) стоимость составила бы ~1,4–2,3M ₽ вместо ~4,8M ₽ по тарифам без кэша (экономия ~2,8×).

Кэширование было включено на стороне клиента, но не сработало из-за ошибки в SDK (несовпадение namespace). Запросить перерасчёт стоимости с учётом этого обстоятельства.
